# Changelog

All notable changes to SocialFlow are documented in this file. The project uses semantic versioning for published reference-architecture revisions.

## [Unreleased]

### Planned

## [0.1.0] - 2026-08-31

### Added

- Account-centric orchestration model and lifecycle
- Priority, scheduled-time, and account-aware task selection
- Scheduler and worker responsibility boundaries
- Bounded retry and failure-recovery design
- Persistent execution-state model
- Minimal workflow engine and dependency semantics
- Local-to-distributed scaling guidance
- Multi-account and retry reference scenarios
- Small Python reference models and scheduler selection function
- Contribution, security, issue, and pull-request guidance
